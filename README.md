# Gem Merge Game

A fun merge puzzle game where you combine identical gems to create larger ones!

## How to Play

1. Click or tap to drop gems
2. Match two identical gems to merge them into a larger one
3. Try to create the biggest gem possible!

## Local Setup

1. Install Node.js from https://nodejs.org/

2. Install serve tool:
   ```bash
   npm install -g serve
   ```

3. Navigate to the game directory:
   ```bash
   cd daxigua-1.0.0
   ```

4. Start the local server:
   ```bash
   serve
   ```

5. Open your browser and visit http://localhost:5000
